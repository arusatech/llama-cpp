## Executive Summary

The Web/PWA implementation enables offline LLM inference directly in browsers through:

- **WebAssembly (WASM)**: llama.cpp compiled to WASM + OPFS for efficient execution
- **Web Workers**: Dedicated worker thread for non-blocking inference
- **Origin Private File System (OPFS)**: Persistent, high-performance model storage
- **Service Workers**: Offline capability for PWAs
- **IndexedDB/LocalStorage**: Metadata and cache storage

**Key Architecture:**
```
Browser Application (TypeScript/React/Vue)
         ↓
Capacitor Web Implementation
         ↓
WebProvider (Provider Interface)
         ↓
Web Worker (llm.worker.ts)
         ↓
WASM Module (llama_engine.wasm)
         ↓
llama.cpp C++ Core (compiled to WASM)
         ↓
Browser APIs (OPFS, IndexedDB, etc.)
```

## WebAssembly (WASM) Foundation

### WASM Compilation

**Emscripten Configuration:**

```bash
# Build WASM with JavaScript SIMD Prototypes (JSPI) support
LLAMA_WASM_JSPI=1 ./scripts/build-wasm.sh

# Optional: pthread support
LLAMA_WASM_PTHREAD=1 ./scripts/build-wasm.sh
```

**Key Compilation Flags:**
```bash
emcc llama.cpp -o llama_engine.js \
  -O3 \                              # Maximum optimization
  -s WASM=1 \                        # Emit WebAssembly
  -s ALLOW_MEMORY_GROWTH=1 \         # Dynamic memory growth
  -s EXPORTED_FUNCTIONS=... \        # Export C++ functions
  -s EXPORTED_RUNTIME_METHODS=... \  # Export runtime methods
  -s USE_PTHREADS=1 \               # (optional) threading support
  -s ASYNCIFY=1 \                   # (optional) async/await support
  -msimd128                          # SIMD support
```

### WASM Module Structure

**Generated Files:**

1. **llama_engine.js** - JavaScript wrapper
   - Handles WASM initialization
   - Module object export
   - Memory management

2. **llama_engine.wasm** - Binary module
   - Compiled C++ code
   - ~30-50 MB for full feature set
   - Lazy loading recommended

3. **llama_engine.d.ts** - TypeScript definitions
   - WASM function signatures
   - Type definitions

```
┌─────────────────────────────────────────┐
│      WASM Linear Memory                 │

```

**Memory Growth:**
- Initial: 256 MB
- Maximum: Dynamic (browser memory limit)
- Auto-grows as model loads
- Respects browser memory constraints

### Performance Characteristics

**WASM vs Native:**
- Speed: 60-80% of native C++ (optimized WASM)
- Memory: Similar footprint to native
- Startup: Requires module initialization
- Compilation: JIT compilation by browser

**Optimization Techniques:**
1. SIMD (Single Instruction Multiple Data)
2. Memory efficiency via quantization
3. Worker thread parallelism
4. Lazy model loading

```typescript
// Message handling
self.onmessage = async (event: MessageEvent) => {
  const { method, id, params } = event.data;

      case 'load_model':
        result = await wasmEngine.loadModel(params);
        break;
      case 'completion':
        result = await wasmEngine.completion(params);
        break;
      // ... other methods
    }
    
    // Send result back to main thread
    self.postMessage({
      id,
      result,
      error: null
    });
  } catch (error) {
    self.postMessage({
      id,
      result: null,
      error: error.message
    });
  }

export function streamToken(token: string) {
  self.postMessage({
    type: 'token',
    token
  });
}
```

### Worker Lifecycle

```
1. Creation (Main Thread)
   ↓
2. Initialization (Worker)
   - Load WASM module
   - Initialize runtime
   ↓
3. Ready (Worker→Main)
   ↓
4. Operations (Main→Worker)
   ↓
5. Results (Worker→Main)
   ↓
6. Cleanup (Main Thread)
   - Terminate worker
   - Release resources
```

## Storage & File System (OPFS)

### Origin Private File System (OPFS)

**What is OPFS?**
- High-performance file storage
- Origin-private (same-origin policy)
- Synchronous file operations in workers
- Persistent across sessions
- Quota: 50% of available disk space

**Browser Support:**
- Chrome 86+
- Edge 86+
- Firefox (origin trial)
- Safari 15.2+

### File Management

**opfs.store.ts - OPFS Storage Layer:**

```typescript
export async function ensureModelInOpfs(
  modelId: string,
  modelUrl: string,
  onProgress?: (progress: number) => void
): Promise<string> {
  const root = await navigator.storage.getDirectory();
  
  // Check if already cached
  const modelFile = await root.getFileHandle(`models/${modelId}`);
  if (modelFile) {
    return `/tmp/${modelId}`;  // Return WASM VFS path
  }
  
  // Download and save
  const response = await fetch(modelUrl);
  const blob = await response.blob();
  
  // Monitor download progress
  let received = 0;
  const reader = blob.stream().getReader();
  
  const writable = await modelFile.createWritable();
  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    await writable.write(value);
    received += value.length;
    onProgress?.((received / blob.size) * 100);
  }
  
  await writable.close();
  return `/tmp/${modelId}`;
}

export async function listModelsInOpfs(): Promise<string[]> {
  const root = await navigator.storage.getDirectory();
  const modelsDir = await root.getDirectoryHandle('models');
  
  const models: string[] = [];
  for await (const entry of modelsDir.values()) {
    if (entry.kind === 'file') {
      models.push(entry.name);
    }
  }
  
  return models;
}

export async function deleteModelFromOpfs(modelId: string): Promise<void> {
  const root = await navigator.storage.getDirectory();
  const modelsDir = await root.getDirectoryHandle('models');
  await modelsDir.removeEntry(modelId);
}
```

### WebProvider Implementation

**isomorphic/provider.web.ts:**

```typescript
export class WebProvider implements LlmProvider {
  private workers: Map<string, Worker> = new Map();
  private scheduler: ModelScheduler;
  private loadedModels: Map<string, ModelState> = new Map();
  
  constructor() {
    this.scheduler = new DefaultModelScheduler(3);  // 3 models max
  }

  async initialize(options: InitializeOptions): Promise<void> {
    const { modelId, modelPath } = options;
    
    // Check scheduler capacity
    const canAdmit = this.scheduler.ensureCapacity(modelId);
    if (!canAdmit) {
      // Unload least-used model
      const toUnload = this.scheduler.getLeastUsed();
      await this.unloadModel(toUnload);
    }
    
    // Create worker for this model
    const worker = new Worker('./llm.worker.js');
    this.workers.set(modelId, worker);
    
    // Initialize model in worker
    await this.workerCall(modelId, 'load_model', {
      modelPath,
      n_ctx: options.n_ctx || 2048,
      n_threads: options.n_threads || 4,
    });
    
    // Mark as loaded
    this.scheduler.markLoaded(modelId);
    this.loadedModels.set(modelId, {
      state: 'loaded',
      lastUsed: Date.now(),
      memoryUsage: 0
    });
  }

  async generate(request: GenerateRequest): Promise<GenerateResult> {
    const worker = this.workers.get(request.modelId);
    if (!worker) {
      throw new Error(`Model not loaded: ${request.modelId}`);
    }
    
    // Send completion request
    const result = await this.workerCall(
      request.modelId,
      'completion',
      {
        prompt: request.prompt,
        n_predict: request.n_predict,
        temperature: request.temperature,
        top_p: request.top_p,
        top_k: request.top_k,
      }
    );
    
    // Update last used time
    const model = this.loadedModels.get(request.modelId);
    if (model) {
      model.lastUsed = Date.now();
    }
    
    return result;
  }

  async unloadModel(modelId: string): Promise<void> {
    const worker = this.workers.get(modelId);
    if (worker) {
      worker.terminate();
      this.workers.delete(modelId);
    }
    
    this.scheduler.markUnloaded(modelId);
    this.loadedModels.delete(modelId);
  }

  private workerCall(
    modelId: string,
    method: string,
    params: any
  ): Promise<any> {
    return new Promise((resolve, reject) => {
      const worker = this.workers.get(modelId);
      if (!worker) {
        reject(new Error(`Worker not found for model ${modelId}`));
        return;
      }
      
      const id = Math.random().toString(36);
      const handler = (event: MessageEvent) => {
        if (event.data.id === id) {
          worker.removeEventListener('message', handler);
          if (event.data.error) {
            reject(new Error(event.data.error));
          } else {
            resolve(event.data.result);
          }
        }
      };
      
      worker.addEventListener('message', handler);
      worker.postMessage({ id, method, params });
      
      // Timeout after 5 minutes
      setTimeout(() => {
        worker.removeEventListener('message', handler);
        reject(new Error('Worker timeout'));
      }, 5 * 60 * 1000);
    });
  }
}
```

## Model Management

### Model Scheduler

**isomorphic/model.scheduler.ts:**

```typescript
export interface Scheduler {
  ensureCapacity(modelId: string): boolean;
  markLoaded(modelId: string): void;
  markUnloaded(modelId: string): void;
  listLoaded(): string[];
  getLeastUsed(): string;
}

export class DefaultModelScheduler implements Scheduler {
  private loaded: Map<string, number> = new Map();  // modelId → lastUsed
  private capacity: number;

  constructor(maxModels: number = 3) {
    this.capacity = maxModels;
  }

  ensureCapacity(modelId: string): boolean {
    if (this.loaded.size < this.capacity) {
      return true;
    }
    
    // Can unload if at capacity
    return true;
  }

  markLoaded(modelId: string): void {
    this.loaded.set(modelId, Date.now());
  }

  markUnloaded(modelId: string): void {
    this.loaded.delete(modelId);
  }

  listLoaded(): string[] {
    return Array.from(this.loaded.keys());
  }

  getLeastUsed(): string {
    let leastUsed = '';
    let oldestTime = Infinity;
    
    for (const [modelId, time] of this.loaded) {
      if (time < oldestTime) {
        oldestTime = time;
        leastUsed = modelId;
      }
    }
    
    return leastUsed;
  }
}
```

## WASM Module Integration

### WASM Engine

**workers/wasm.engine.ts:**

```typescript
import WasmModule from '../wasm/llama_engine';

export class WasmEngine {
  private module: WebAssembly.Instance | null = null;
  private memory: WebAssembly.Memory | null = null;

  async initialize(): Promise<void> {
    // Load and instantiate WASM module
    this.module = await WasmModule({
      env: {
        // Provide host functions to WASM
        log_callback: (level: number, text: string) => {
          console.log(`[WASM:${level}] ${text}`);
        }
      },
      // Enable memory growth
      memory: new WebAssembly.Memory({ initial: 256, maximum: 512 }),
    });
    
    this.memory = this.module.memory;
  }

  async loadModel(params: {
    modelPath: string;
    n_ctx: number;
    n_threads: number;
  }): Promise<{ contextId: number }> {
    // Call WASM function to load model
    const contextId = this.module!.exports.llama_init_context(
      this.stringToWasm(params.modelPath),
      params.n_ctx,
      params.n_threads
    );
    
    return { contextId };
  }

  async completion(params: {
    contextId: number;
    prompt: string;
    n_predict: number;
    temperature: number;
    top_p: number;
    top_k: number;
  }): Promise<{ text: string; tokens: string[] }> {
    // Call WASM completion function
    const resultPtr = this.module!.exports.llama_completion(
      params.contextId,
      this.stringToWasm(params.prompt),
      params.n_predict,
      params.temperature,
      params.top_p,
      params.top_k
    );
    
    // Read result from WASM memory
    const result = this.readResultFromMemory(resultPtr);
    
    return result;
  }

  private stringToWasm(str: string): number {
    const encoder = new TextEncoder();
    const buffer = encoder.encode(str + '\0');
    
    // Allocate in WASM memory
    const ptr = this.module!.exports.malloc(buffer.length);
    const wasmArray = new Uint8Array(this.memory!.buffer, ptr, buffer.length);
    wasmArray.set(buffer);
    
    return ptr;
  }

  private readResultFromMemory(ptr: number): any {
    // Parse JSON result from WASM memory
    const view = new Uint8Array(this.memory!.buffer, ptr);
    let end = 0;
    while (view[end] !== 0) end++;
    
    const str = new TextDecoder().decode(view.slice(0, end));
    return JSON.parse(str);
  }
}
```

```typescript
export class AsyncFileSystem {
  private fileHandles: Map<string, FileSystemFileHandle> = new Map();

  async openFile(path: string): Promise<File> {
    const root = await navigator.storage.getDirectory();
    
    // Navigate to file
    const parts = path.split('/').filter(Boolean);
    let current: any = root;
    
    for (const part of parts.slice(0, -1)) {
      current = await current.getDirectoryHandle(part);
    }
    
    const handle = await current.getFileHandle(parts[parts.length - 1]);
    this.fileHandles.set(path, handle);
    
    return handle.getFile();
  }

  async readFile(path: string): Promise<Uint8Array> {
    const file = await this.openFile(path);
    const buffer = await file.arrayBuffer();
    return new Uint8Array(buffer);
  }

  async writeFile(path: string, data: Uint8Array): Promise<void> {
    const root = await navigator.storage.getDirectory();
    const parts = path.split('/').filter(Boolean);
    
    // Create directories as needed
    let current: any = root;
    for (const part of parts.slice(0, -1)) {
      current = await current.getDirectoryHandle(part, { create: true });
    }
    
    // Write file
    const fileName = parts[parts.length - 1];
    const handle = await current.getFileHandle(fileName, { create: true });
    const writable = await handle.createWritable();
    
    await writable.write(data);
    await writable.close();
  }
}
```

```typescript
export class HeapFileSystem {

  register(path: string, data: Uint8Array): void {

      throw new Error(`File not found: ${path}`);
    }
    
    return file.slice(offset, offset + length);
  }

  stat(path: string): { size: number; isDirectory: boolean } {
    const file = this.files.get(path);
    if (!file) {
      throw new Error(`File not found: ${path}`);
    }
    
    return {
      size: file.byteLength,
      isDirectory: false
    };
  }

  list(path: string): string[] {
    const prefix = path.endsWith('/') ? path : path + '/';
    const files: string[] = [];
    
    for (const file of this.files.keys()) {
      if (file.startsWith(prefix) && !file.slice(prefix.length).includes('/')) {
        files.push(file);
      }
    }
    
    return files;
  }
}
```

## Streaming & Performance

### Streaming Inference

**Web Provider Streaming:**

```typescript
async streamingCompletion(
  modelId: string,
  prompt: string,
  onToken: (token: string) => void
): Promise<NativeCompletionResult> {
  const worker = this.workers.get(modelId);
  
  return new Promise((resolve, reject) => {
    const id = Math.random().toString(36);
    
    const tokenHandler = (event: MessageEvent) => {
      if (event.data.type === 'token' && event.data.requestId === id) {
        onToken(event.data.token);
      }
    };
    
    const doneHandler = (event: MessageEvent) => {
      if (event.data.id === id && event.data.type === 'done') {
        worker!.removeEventListener('message', tokenHandler);
        worker!.removeEventListener('message', doneHandler);
        resolve(event.data.result);
      }
    };
    
    worker!.addEventListener('message', tokenHandler);
    worker!.addEventListener('message', doneHandler);
    
    worker!.postMessage({
      id,
      method: 'stream_completion',
      params: { prompt }
    });
    
    setTimeout(() => reject(new Error('Timeout')), 30 * 60 * 1000);
  });
}
```

### Performance Optimization

**Techniques:**

1. **Lazy Module Loading**

2. **Memory Pooling**
   ```typescript
   class MemoryPool {
     private buffers: Uint8Array[] = [];
     
     allocate(size: number): Uint8Array {
       const buffer = this.buffers.find(b => b.byteLength >= size);
       if (buffer) {
         this.buffers = this.buffers.filter(b => b !== buffer);
         return buffer;
       }
       return new Uint8Array(size);
     }
     
     release(buffer: Uint8Array): void {
       this.buffers.push(buffer);
     }
   }
   ```

   - Minimal quality loss

4. **Context Limiting**

   - Matches browser memory constraints
   - Maintains responsiveness

```typescript
async function loadModelWithRetry(
  modelId: string,
  modelUrl: string,
  maxRetries: number = 3
): Promise<string> {
  for (let attempt = 0; attempt < maxRetries; attempt++) {
    try {
      return await ensureModelInOpfs(modelId, modelUrl);
    } catch (error) {
      if (attempt === maxRetries - 1) {
        throw new Error(`Failed to load model after ${maxRetries} attempts: ${error}`);
      }
      
      // Exponential backoff
      await new Promise(r => setTimeout(r, Math.pow(2, attempt) * 1000));
    }
  }
  
  throw new Error('Failed to load model');
}
```

| SharedArrayBuffer | 68+ (COOP/COEP) | Trial | - | 79+ |
| IndexedDB | All | All | All | All |

### Feature Fallbacks

**If OPFS not available:**
- Fall back to IndexedDB
- Download model on each session
- Larger app startup time

**If Web Workers not available:**
- Use main thread
- UI may freeze during inference
- Single-threaded operation
